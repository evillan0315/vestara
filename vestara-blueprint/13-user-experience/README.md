## 🎨 UX Principles

| Principle | Description |
|-----------|-------------|
| **Invisible** | The best interface is the one you don't notice |
| **Instant** | Every interaction feels immediate (<100ms feedback) |
| **Confident** | Undo, not "are you sure?" |
| **Adaptive** | Learns from user behavior, adapts to context |
| **Accessible** | WCAG 2.1 AA minimum, AAA target |
| **Consistent** | Same patterns across all surfaces |
| **Progressive** | Simple by default, powerful on demand |
| **Human** | Warm, empathetic, never robotic |
